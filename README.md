# n8n Workflow Automation on Render Cloud

Production deployment of [n8n](https://n8n.io/) on Render Cloud paired with Neon Serverless PostgreSQL for persistent workflow storage.

### Features
- 🚀 Uses official `n8nio/n8n:latest` Docker image.
- 💾 Persistent database on **Neon Cloud PostgreSQL** (Free tier, never expires).
- 🔒 Encrypted credentials with auto-generated encryption key.
- ⚡ Optimized for Render Free Tier (Port 5678 mapped).
